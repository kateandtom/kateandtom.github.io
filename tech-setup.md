# Tech Setup

## Public Website

I'll build a simple static site hosted on **GitHub Pages** (free). The design will be modeled after [corinwagen.github.io](https://corinwagen.github.io) — clean, minimal, text-first, with a simple gray nav bar and Roboto font. The site's source code is a useful template: [github.com/corinwagen/corinwagen.github.io](https://github.com/corinwagen/corinwagen.github.io).

The site will have:
- A blog/journal section for posts I want to share publicly
- An about/intro page
- An embedded Google My Maps for location tracking (see below)

Everything stays simple — hand-written HTML or a minimal static site generator, no CMS, no build complexity.

## Location Tracking

I'll use **Google My Maps** to track my progress along the trail. A map will be embedded on the website so people can follow where I am. Google My Maps is free and lets me add points, routes, and notes without any coding.
